# Ansible Ad-Hoc Commands

This directory contains commonly used Ansible ad-hoc commands for performing quick administrative tasks without writing playbooks.

Ad-hoc commands are ideal for one-time operations such as checking connectivity, installing packages, managing services, creating users, copying files, gathering system information, and troubleshooting remote servers.

## Topics Covered

- Ping Commands
- Package Management
- Service Management
- User Management
- File Management
- System Information
- Networking
- Process Management
- Miscellaneous Commands

> **Note:** Ad-hoc commands are best suited for simple, one-time tasks. For repeatable and complex automation, Ansible Playbooks are recommended.
