# Dynamic Inventory

Dynamic Inventory allows Ansible to automatically discover managed hosts from cloud providers instead of maintaining a static inventory file.

As cloud environments are dynamic, servers are frequently created, terminated, or assigned new IP addresses. Dynamic Inventory ensures that Ansible always works with the latest infrastructure information.

This directory contains examples of configuring and using Dynamic Inventory with major cloud providers.
