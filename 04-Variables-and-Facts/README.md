# Variables and Facts

Variables make Ansible playbooks flexible, reusable, and easier to maintain by allowing values to be defined once and referenced throughout the automation.

Facts are system information automatically gathered from managed nodes, such as operating system, hostname, IP address, memory, CPU, and network interfaces.

This directory demonstrates different methods of defining variables, gathering facts, using registered variables, and understanding variable precedence.
