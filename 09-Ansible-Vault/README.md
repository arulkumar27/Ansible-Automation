# Ansible Vault

Ansible Vault is a built-in feature that protects sensitive information by encrypting files and variables.

Instead of storing passwords, API keys, SSH keys, or database credentials in plain text, Ansible Vault securely encrypts them while still allowing playbooks to use the values during execution.
