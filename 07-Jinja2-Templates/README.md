# Jinja2 Templates

Jinja2 is the default templating engine used by Ansible to generate dynamic configuration files. It allows variables, conditions, loops, filters, and expressions to be embedded inside text files, making configurations reusable across multiple environments.

Templates are commonly used to create web server configurations, application configuration files, HTML pages, SSH configurations, Docker daemon settings, and many other system files.
