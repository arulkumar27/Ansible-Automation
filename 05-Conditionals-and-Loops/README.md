# Conditionals and Loops

Conditionals and loops make Ansible playbooks dynamic, reusable, and intelligent. They allow tasks to execute only when specific conditions are met and enable repetitive operations without duplicating code.

This directory contains practical examples demonstrating how to use conditional statements, loops, retries, filters, and error handling to automate real-world infrastructure tasks.

## Topics Covered

- when
- Multiple Conditions
- failed_when
- changed_when
- Loops
- Dictionary Loops
- Registered Variables
- Until & Retry
- Filters
- Ternary Operator
- JSON Query

## Skills Demonstrated

- Dynamic Automation
- Decision Making
- Error Handling
- Data Processing
- Iterative Operations
- Idempotent Playbooks
