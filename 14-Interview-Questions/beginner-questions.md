# Beginner Interview Questions

## 1. What is Ansible?

Ansible is an open-source configuration management, automation, and orchestration tool used to automate server provisioning, application deployment, configuration management, and infrastructure tasks over SSH.

---

## 2. Why do we use Ansible?

- Eliminates repetitive manual work
- Reduces configuration errors
- Ensures consistency
- Automates infrastructure
- Supports Infrastructure as Code (IaC)

---

## 3. What are the advantages of Ansible?

- Agentless architecture
- Easy to learn
- Uses SSH
- YAML-based playbooks
- Idempotent
- Cross-platform support

---

## 4. What is Inventory?

Inventory is the file that contains the list of managed hosts and groups on which Ansible executes tasks.

---

## 5. What is a Playbook?

A Playbook is a YAML file that defines automation tasks executed on managed hosts.

---

## 6. What are Modules?

Modules are reusable units of work that perform specific tasks such as installing packages, managing services, creating users, or copying files.

---

## 7. What are Ad-Hoc Commands?

Ad-Hoc Commands are one-line Ansible commands used for quick administrative tasks without creating a playbook.

---

## 8. What is YAML?

YAML (YAML Ain't Markup Language) is a human-readable data serialization language used to write Ansible playbooks.

---

## 9. What are Facts?

Facts are system information automatically gathered by Ansible, such as hostname, operating system, IP address, memory, and CPU details.

---

## 10. What is Idempotency?

Idempotency means running the same playbook multiple times produces the same final system state without unnecessary changes.
